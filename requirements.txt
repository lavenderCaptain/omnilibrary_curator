# --------------------------------------------------------------------------
# NOTES
# --------------------------------------------------------------------------
# * DuckDB 1.5.6 ships a native DOUBLE[] array type but NOT the `vector`
#   extension (duckdb-vector), which currently does not host an Apple Silicon
#   build (HTTP 404). Vectors are therefore stored as DOUBLE[] columns until a
#   compatible vector extension becomes installable. The database layer
#   abstracts this so it can be swapped to real VECTOR types later without
#   touching callers.
# * exiftool itself is a separate Homebrew formula (`brew install exiftool`).
#   It is an optional acceleration path; the scanner works without it.
# --------------------------------------------------------------------------
